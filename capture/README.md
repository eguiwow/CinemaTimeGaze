# KnowMan Capture launcher (temporary home)

An installable shell (PWA) that opens Ander's KnowMan capture page. It holds no data and no link: the link is pasted once on the phone and kept there.

It lives here only because this repository already has GitHub Pages. The source is `modules/launcher` in the KnowMan repository. It moves to its own public repository later. The Pages workflow copies this folder to `docs/capture/`, so it is served at `/CinemaTimeGaze/capture/`.
